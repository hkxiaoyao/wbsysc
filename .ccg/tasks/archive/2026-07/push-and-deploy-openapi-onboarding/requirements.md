# 推送并部署 OpenAPI 极速接入

## 目标

- 将本地 `main` 上已验证的 OpenAPI 极速接入提交推送到配置的远端。
- 使用仓库既有生产部署流程发布到 `211.159.172.117:/root/app/wbsysc`。
- 不在命令、日志、任务文件或 Git 中记录服务器密码。

## 安全与验收

- 推送前确认工作区、上游分支和远端是否存在分叉，不强推。
- 部署前识别并使用现有脚本、服务管理和数据库迁移流程，不临时发明不可回滚流程。
- 生产部署必须保留当前版本/提交信息用于回滚。
- 部署后验证服务进程、健康接口、前端静态资源以及 OpenAPI 新路由可达性。
- 检查近期错误日志，不输出 Token、密码或连接凭据。
