# OpenAPI 极速接入第一期

## 用户目标

将普通 OpenAPI 接入从 8 个工程步骤压缩为两个页面：导入规范，以及填写凭据/确认写权限后测试并启用。管理员和租户后台应使用同一流程。

## 第一期开启范围

- 支持上传或粘贴 JSON/YAML OpenAPI；本期不增加 URL 拉取。
- Spec ID、修订号、导入、验证、发布、默认工具策略、只读测试、激活由系统编排。
- 无组合声明时，一项 operation 生成一个 MCP 工具。
- 只读工具默认启用；写工具默认关闭，只有用户显式确认的写工具才启用。
- 凭据使用后端批准 schema 生成表单或受控对象，不显示/读回既有值。
- 高级组合工具、手工修订与逐阶段操作继续保留，但默认折叠。

## 安全与一致性

- 不放宽租户边界、同源校验、凭据加密、审计和出站请求控制。
- 写操作不能自动启用。
- 激活前必须通过后端验证与真实安全只读测试。
- 编排失败不得留下活动的半配置修订；错误响应不得包含凭据或上游敏感信息。
- 接口应具备明确的版本/摘要校验，避免分析结果与激活输入发生竞态。

## 非目标

- URL 导入、远程 `$ref`、Postman/cURL 导入。
- AI 自动生成映射。
- 删除现有高级向导能力。
